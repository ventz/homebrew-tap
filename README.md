# Homebrew Tap

Homebrew casks for my macOS apps.

## Quick Install

```bash
brew install --cask ventz/tap/wombat-wireguard
```

## Casks

| Cask | App |
| --- | --- |
| `wombat-wireguard` | [Wombat](https://wombat.vpetkov.net), a native WireGuard and AmneziaWG client for macOS. Installs the app and links the `wombat` command into Homebrew's `bin`. |

The apps update themselves (Sparkle), so `brew upgrade` leaves them alone unless you pass
`--greedy`.
